# WingRPG (2.5D D20 Turn-Based RPG)

Unity 6 (6000.6.0f1) 기반의 2.5D 턴제 RPG 프로젝트입니다. 3D 환경과 2D 스프라이트가 공존하는 쿼터뷰 탐색 필드에서 적 심볼과 조우하여, 물리 D20 주사위 기반의 3 vs 3 턴제 전투를 치르고 다시 모험 필드로 복귀하는 완전한 게임플레이 루프를 제공합니다.

---

## 🎮 주요 시스템 및 특징

### 1. 2.5D 탐색 필드 및 심볼 인카운터 (`Level01_Exploration`)
- **2.5D 쿼터뷰 필드 탐색**: 3D 지형 위에서 2D 스프라이트 캐릭터 이동 (New Input System 대응).
- **심볼 인카운터 시스템**: 필드에 배치된 적 심볼(고블린, 오크, 슬라임)에 근접 시 전투 씬으로 자연스럽게 전이.
- **상호작용 이벤트**: 황금 보물상자(골드/엘릭서 획득) 및 방랑 기사 NPC 대화 이벤트.
- **적 처치 영속성 반영**: 전투 승리 후 필드로 복귀 시, 처치된 적 심볼은 `GameManagerData.DefeatedEnemyIDs`를 기반으로 자동 비활성화되어 맵에서 사라집니다.

### 2. D20 물리 주사위 및 타격 피드백 시스템
- **D20 물리 주사위 롤러**: 20면체 물리 메시 기반 주사위 굴림 및 상단 면 감지.
  - **눈금 1 (대실패, Critical Fail)**: 공격 빗나감 / 대미지 0.
  - **눈금 2~19 (일반 타격)**: 눈금 값에 비례하여 위력 배율 선형 증가.
  - **눈금 20 (대성공 / 즉사, Instant Kill)**: 대상의 남은 체력과 무관하게 즉사 판정.
- **주사위 비례 타격감 피드백**:
  - **히트스톱 (Hit-Stop)**: 주사위 결과에 비례하여 `Time.timeScale`을 일시 감속/정지 후 복구.
  - **2.5D 카메라 셰이크**: Perlin 노이즈 기반 쿼터뷰 맞춤형 진동 연출.
  - **절차적 오디오**: 타격/성공/실패 사운드 자동 생성.

### 3. 아군 3인 vs 적군 3인 턴제 전투 루프
- **스피드 기반 턴 타임라인**: 캐릭터 스피드 스탯에 따라 라운드별 행동 순서 동적 정렬.
- **스킬 시스템**: 참격(Slash), 연속 베기(Dual Strike), 결전 강타(Heavy Blow) 등 고유 배율 스킬.
- **적 AI**: 남은 HP 비율이 가장 낮은 아군을 타깃팅하는 스마트 AI.
- **전투 승리 및 탐색 복귀**: 승리 팝업의 [확인 (탐색으로 복귀)] 버튼 클릭 시 `SceneManager.LoadSceneAsync("Level01_Exploration")`를 통해 안전하게 필드로 복귀.

### 4. 영속 데이터 관리 (`GameManager`)
- `Assets/Data/GameManagerData.asset` ScriptableObject를 통해 플레이어 위치, 보유 골드, 인벤토리, 처치한 적 심볼 목록(`DefeatedEnemyIDs`)을 씬 전환 시에도 영구 보존.
